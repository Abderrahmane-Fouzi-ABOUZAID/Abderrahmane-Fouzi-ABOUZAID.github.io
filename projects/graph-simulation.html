C / Graph theory / Solo academic project

Dynamic malware propagation simulation

A simulation engine that models stochastic malware transmission across a vehicle-to-vehicle network whose topology changes at every timestep.

Role
Solo implementation
Language
C
Model
Dynamic weighted graph
Output
GraphViz snapshots

01 / Model

A network edge exists only while two moving vehicles are close enough.

Each vehicle tracks position, velocity, and a susceptible, infected, or recovered state. At each timestep, the engine recalculates connectivity from Euclidean distance and a configurable danger radius.

  1. MoveUpdate each vehicle position
  2. ConnectRebuild distance-based edges
  3. TransmitApply stochastic infection
  4. TransitionUpdate SIR state
  5. RenderWrite GraphViz snapshot

02 / Decisions

Prefer a transparent model over a hidden simulation framework.

Topology

Dynamic adjacency matrix

An O(N²) pass recalculates edges from current vehicle positions at every step.

Transmission

Weighted probability

Connected infected and susceptible vehicles use a configurable stochastic transmission probability.

State

SIR representation

Explicit susceptible, infected, and recovered states make each transition inspectable.

Evidence

120 GraphViz frames

Generated dot files allow propagation clusters and infection paths to be inspected over time.

03 / Proof

The implementation is public.

The repository contains the C source and generated graph workflow. Unlike the private internship and partner projects, this case can be inspected directly.
